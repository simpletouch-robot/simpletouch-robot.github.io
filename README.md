# SimpleTouch Project Page

Project website for **SimpleTouch: Can Vision-Language-Action Models Master
Contact-Rich Manipulation Without Tactile Policy Pretraining?**

[Website](https://simpletouch-robot.github.io/) ·
[Paper](https://arxiv.org/pdf/2610.02784) ·
[arXiv](https://arxiv.org/abs/2610.02784) ·
[Code](https://github.com/ccyydd/SimpleTouch) ·
[Checkpoints](https://huggingface.co/cyang203912/SimpleTouch)

This is a static website. GitHub Pages serves the repository root on `main`.

For local preview, serve this directory with a static HTTP server. The images,
video, captions, fonts, and result data are in `assets/`.
